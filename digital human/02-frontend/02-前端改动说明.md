## 1. `index.html`（head 加 1 行 script）

在 `</head>` 前加（完整版见 `index.html`）：
```html
<script src="https://media.xingyun3d.com/xingyun3d/general/litesdk/xmovAvatar@latest.js"></script>
```
**为什么**：SDK 加载后全局注入 `XmovAvatar` 构造函数。**不用装 npm 包、不用改 Vite**（魔珐路线的优势）。

> ⚠️ 魔珐 SDK 只认 `localhost` 或 HTTPS。你前端 Vite 配的是 `127.0.0.1:5173`，可用；生产上必须 HTTPS 域名。

- **改动 2**（第 567 行 `onUnmounted` 里）：加 `liteSDK?.destroy()` 防并发超限 10005。

## 关键行为说明

| 场景 | 表现 |
|---|---|
| 默认（没连） | 数字人列显示「连接数字人」按钮 + 黑屏占位；**原有 TTS 🔈 按钮行为完全不变** |
| 点了连接 | 取凭证 → `new XmovAvatar` → `init()` 下资源 → 进度 100% → 数字人出现，按钮变「断开」 |
| 连上后发一条消息 | Bot 文字回复出来的同时，数字人自动 `speak()` 读出来 + 动唇形 |
| 点断开 / 关页面 | `destroy()` 释放连接 |
| 没填 `.env` 凭证 | 连接时报「后端未配置数字人凭证」提示，不崩 |

## 合并后验证

# 3. F12 确认：前端源码搜不到明文凭 AppId/AppSecret（已从后端动态取）
