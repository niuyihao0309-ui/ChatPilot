## 1. `conf/config.py`（在 `app_port: int` 后加 3 字段）

**原代码**：
```python
    # 服务器
    app_host: str
    app_port: int

    # 从.env文件中读取配置信息
```
**改成**（完整版见 `conf_config.py`）：
```python
    # 服务器
    app_host: str
    app_port: int

    # 数字人（魔珐星云）
    digital_human_app_id: str = ""
    digital_human_app_secret: str = ""
    digital_human_gateway_server: str = "https://nebula-agent.xingyun3d.com/user/v1/ttsa/session"

    # 从.env文件中读取配置信息
```
**为什么**：`pydantic-settings` 自动把 `.env` 的 `DIGITAL_HUMAN_APP_ID` 映射为 `digital_human_app_id`。
给 `app_id/app_secret` 默认空串 = **没填凭证时应用不炸**，接口返回空值、前端提示去填 `.env`。

## 2. `api/app.py`（加 1 行 import + 1 行 include_router）

**原代码**：
```python
from api.routers.chat_router import router
...
app.include_router(router)
```
**改成**（完整版见 `api_app.py`）：
```python
from api.routers.chat_router import router
from api.routers.digital_human_router import router as digital_human_router   # 新增
...
app.include_router(router)
app.include_router(digital_human_router)   # 新增
```
**为什么**：注册凭证接口。魔珐路线**不用改 `lifespan`**（不像灵眸要初始化阿里云客户端）—— 简单就简单在这。

## 3. 新建 `api/routers/digital_human_router.py`

整文件见 `digital_human_router.py`。
`GET /api/digital-human/credentials` 返回 `app_id / app_secret / gateway_server`，**密钥只存后端**。

## 4. `.env` 追加 3 行（见 `env.snippet`）

把 `你的AppId/你的AppSecret` 换成魔珐后台真实值。网关地址一般不改。

## 5. 新建 `.gitignore`（见 `gitignore.snippet`）

你项目根目录现在**没有 `.gitignore`**。`.env` 有密钥，必须挡在 git 外。
